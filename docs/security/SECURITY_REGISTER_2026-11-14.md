# Security register: dependency and code-scanning alerts (2026-11-14)

This register covers the GitHub code-scanning (CodeQL) and Dependabot alerts that were open on `main` at merge
commit `1fd5608`. Both alert lists were fetched live on 2026-11-14. Each alert was triaged against the code and its
data flow. Fixes are proposed only as small, separate draft PRs; nothing has been merged and no alert has been
dismissed.

## Classifications

- **EXPLOITABLE**: there is a concrete attack path, which may be conditional.
- **FALSE_POSITIVE**: the flagged code is not reachable with attacker input, either because the value is validated
  or contained before use, or because the dependency's vulnerable path is never exercised or never shipped.
- **ACCEPTED_RESIDUAL**: the issue is real but local-only or dev-only. It is accepted under the conditions stated.

Severity is the tool's severity. Out of scope here: pypdf and the PDF parser (finding P2-11, owned by another work
item), and N-1 (`src/pados/control/service.py`, `src/pados/operations/service.py`).
