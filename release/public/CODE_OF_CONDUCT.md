# Code of conduct

- **Be respectful and constructive.** Critique ideas and code, not people.
- **No harassment.** No harassment, discrimination, personal attacks or unwelcome sexual attention, in any project space.
- **Assume good faith.** Help newcomers, and keep discussions on topic.
- **Enforcement.** Maintainers may remove content and restrict participation to enforce this. Report problems privately to the maintainers (contact published with the repository).
